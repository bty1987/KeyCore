## 坐标系与朝向（关键，装反全盘错位）

- EDA 坐标系 = **立创EDA 顶视图（元件面朝上）**，原点 PCB 左下角，+x 向右，+y 向**后（Esc/宏排侧）**。
- PCB 外形 **300×192mm**（2026-10-07 定，与屏幕外围 300.2 同宽）；scad v4 坐标 = (EDA_x, 192 + EDA_y)（y-up 距前缘）。
- **霍尔位 = 键位**（孔心=霍尔位，2026-10-07 拍板）。布板/开孔以 EDA 实测霍尔位为准，禁止手填。

## 装配顺序（厚板盲孔版）

1. 屏入底壳屏托圈（搭接 2mm/边，排线朝后入仓缺口）；
2. 键帽块从上方落入盲孔（先不装磁铁试滑配）；逐块压入侧壁磁铁（N 朝下，同向批量）点 401 胶；
3. 厚板坐入托肩（托肩面距屏 4mm = 静止悬浮气隙）；
4. PCB 落支撑柱（M2.5×6），USB-C 对左墙开口；霍尔面朝上；
5. 驱动板仓内平放、HDMI/12V 背墙出线；封箱前 OSD 设定一次（亮度 40~60%、HDMI、关自动关屏）。
