## 一、设计概要

磁悬浮键帽（无机械轴）：帽体为 **17.05×17×7.5mm 方块**（1u），左右侧壁各有一个
**Ø4.1 水平竖立磁腔**（跨 z 0~4.1，轴心高 2.05），各嵌 1 颗 **N52 4×2 圆盘磁铁（竖放）**，
N 极同向朝邻键缝隙——与厚板磁道内的平贴对斥磁/缝道构成悬浮+回弹磁路。

- 帽间总间隙 2.0mm（单边 1.0），直壁防邻键干涉
- 极面外壁 0.5mm，极面间隙 ≈2.05+2×0.5≈3.05mm（目标 ≥2，越小斥力越强）
- 顶面圆角 R2、下段圆角 R1.2；顶面贴字符片（透明键帽可透 13.3" 屏光）

## 二、变体与数量（封板 5c 实配 67 键）

| 键宽 wu | 帽宽 cap_w | 孔宽(厚板) | 数量 | 用途 |
|---|---|---|---|---|
| 1.0 | 17.05 | 17.65 | **52** | 主键区 |
| 1.25 | 21.81 | 22.41 | 7 | R2 行·Ctrl/Win 等 |
| 1.5 | 26.58 | 27.18 | 2 | R2 行·Tab/\ |
| 1.75 | 31.34 | 31.94 | 1 | R2 行·Caps |
| 2.0 | 36.10 | 36.70 | 1 | R1 行·Backspace |
| 2.25 | 40.86 | 41.46 | 2 | R3 行·Shift ×2 |
| 2.75 | 50.39 | 50.99 | 1 | R4 行·Shift |
| 6.25 | 117.06 | 117.66 | 1 | 空格 |

公式：`cap_w = wu×19.05 − 2.0`；`孔宽 = cap_w + 0.6`；`磁心横偏 = wu×9.525 − 2.5`

## 三、尺寸明细（1u 基准，宽键随 wu 公式）

| 尺寸 | 值 | 备注 |
|---|---|---|
| 帽宽 cap_w | 17.05 | = wu×19.05−2.0 |
| 帽深 cap_d | 17.0 | 行向 |
| 帽高 cap_h | 7.5 | 下段 6.5 + 顶带 1.0 |
| 下段圆角 | R1.2 | 侧壁直立段 |
| 顶面圆角 | R2.0 | 顶带 1.0mm |
| 磁腔直径 | Ø4.1 | 磁铁 4×2 +0.1 公差 |
| 磁腔轴心高 | 2.05 | 腔跨 z 0~4.1（竖放） |
| 磁心横偏 ±7.025 | (1u) | = wu×9.525−2.0−0.5(壁) |
| 磁腔深（插深） | cap_w/2−磁偏+1.1 | 外壁打穿，外侧开口 |
| 壁后极面距 | 磁心+2.05 到外壁 | 剩 0.5mm 外壁（工艺最薄） |

磁铁：**2×N52 圆盘 Ø4×2mm/键，竖放（轴向竖直），同排全部同向**，从侧壁外侧开口水平推入。

## 四、制造与打印

| 项 | 建议 |
|---|---|
| 材质 | 光敏树脂（高精，磁腔免扩孔）或 PETG（耐敲） |
| 打印方向 | **倒立**（顶面朝板），顶圆角免支撑 |
| 公差 | 磁腔 Ø +0.1（过盈推入，免胶）；孔配合已由厚板 +0.6 承担 |
| 后处理 | 磁腔口去毛刺 → 磁铁推入（N 极同向）→ 顶面贴字符片 |
| 校验 | 试装厚板试装孔（v4 test_plate()）手感：悬浮高度、摇晃量、回弹 |

⚠ 磁铁方向铁律：同排键帽全部同向（N 朝同一侧邻缝），装反=相邻键吸死。
