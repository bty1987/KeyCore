## 1. 架构（一张图 + 一段话）

```
z=34.6 ┌─────────────────────────────────────────┐ 顶
       │ ① 厚板 9mm 亚克力（67 盲孔嵌帽，顶露帽 1.5）│
z=25.6 ├─────────────────────────────────────────┤ ← 板底=块底（托肩承板）
       │ ② 键帽块 17×17×7.5：左右侧壁各嵌 4×2 ×1   │ ← 磁心高块底 1.05，N 朝下
       │    侧壁互斥=居中+回弹（邻键磁距 8.05mm@1u） │   行程 3mm
z=21.6 ├─────────────────────────────────────────┤ ← 屏面（块底静止=气隙4mm，按到底距屏1mm）
       │ ③ IPS 屏体 2.5mm（磁场穿透无阻碍，P0 验证） │
z=19.1 ├─────────────────────────────────────────┤ ← 空气隙 2mm（温漂防线）
       │ ④ 霍尔 PCB 1.6mm（霍尔=左侧磁铁正下方）     │    磁心-霍尔 ≈8.5 → 5.5mm
z=15.5 ├─────────────────────────────────────────┤ ← PCB底；下方 12.5mm 驱动板仓
       │ ⑤ HDMI驱动板（仓内平放，背墙出线）          │
z=3.0  └─────────────────────────────────────────┘ 底
       外廓 314×201，总高 ≈34.6mm（与 v1.6 持平）
```

原理一句话：键帽侧壁的磁铁被屏后霍尔感知（屏不导磁，隔屏检测 P0 已实锤；霍尔对准磁铁是信号关键——方案 D 实测全幅 1163mV）；相邻键帽侧壁磁铁互斥提供居中与回弹（复刻 Flux Maglev）；屏在键帽正下方画键位字符，透过透明帽身可见；按键数据走 USB HID 给电脑，同时串口发给渲染端做高亮联动。

## 4. PCB 打版七步（P2 详细流程）

> 立创EDA（浏览器免费，Mac 友好）+ 嘉立创，EDA 与打样厂一体。华秋等价（马同学用的华秋）。

1. **注册** [pro.lceda.cn](https://pro.lceda.cn)，工程存云端。
2. **器件全选"立创贴片库"**（保证 SMT 能贴）：HAL49E SOT-23-3、74HC4051D SOIC-16、ESP32-S3-WROOM-1-N4、USB-C 16P 母座、ME6211C33、0805 阻容。
3. **原理图**：61 霍尔 OUT → 8 片 4051 的 X0~X7（64 通道用 61）；8 片地址线 A/B/C 并联 → 3 个 GPIO，E 接地，Z 输出并联 → GPIO4（ADC1）；Z 与 ADC 间 100Ω + 100nF；ESP32 最小系统（LDO/EN/BOOT/USB-C，Strapping 照抄模组手册典型电路）；可选 DS18B20 ×2 与背光 PWM 脚。
4. **Layout（★v4 形态改版 10-02 拍板）**：板框 **300×172mm**（+26 在宏行侧；空格排=键盘最底边，下方零器件；**元件带全部在宏行侧硬件带 EDA y136~172**：9×4051 排 y143 + ESP32(280,150) 天线朝顶边（禁布区 x271~289/y159~169 无铜无孔）+ USB-C 顶边 x=150 出线 + LDO/按键/阻容；前段 y0~23 只留安装孔与 3V3 Lane；**4 层板**（GND/3V3 内层平面）。屏内自定义区（屏盖键区外的38.3mm）与屏外硬件带（26.4mm）分层放玩法与硬件，互不占用）；67 霍尔按 [pcb-hall-positions.csv](../02-结构图纸/pcb-hall-positions.csv) **v5.0** 坐标放置（**霍尔=每键左侧磁铁正下方 hall_x=mag1_x**；坐标系=EDA顶视图，+y 向 Esc/宏行侧）；模拟区铺地完整；ESP32 天线区悬空；丝印白字标键位；黑色阻焊哑光。~~悬浮磁铁粘接点~~（v5.0 板侧无磁铁，删）。
5. **DRC → 一键导出** Gerber + BOM + 坐标文件。
6. **下单**：2 层 / 1.6mm / 无铅喷锡 / 黑色阻焊白字 / 5 片；SMT 勾顶部贴片、经济型、传 BOM+坐标。3~7 天到货。
7. **验板**：目检 → 3.3V/GND 不短路 → 烧 blink → 刷 ADC 扫描器，磁铁逐键晃过。

**采样细节**（v1.3 诚实口径 + v2.0 信号量更新）：4051 切换后 ~10µs 稳定，弃第一次采样取第二次；`analogReadMilliVolts()` 单次 ~50-100µs → 67 键一轮 **8~11ms ≈ 100~140Hz**，打字绰绰有余（人手最快连击 ~20Hz）。要 RT 电竞级 1kHz 需 P5 改 DMA 连续采样（esp_adc continuous mode，工程量半天）。信号量（v5.0）：4×2 侧壁磁铁磁心距霍尔 ≈8.5→5.5mm，按 P0 实测外推 Δ≈250~400mV（方案 D 同数量级实测全幅 1163mV 背书），余量充足；**P0′ 以实测为准，弱则侧壁腔加深换 6×3 或双 4×2 叠**。

## 5. 键帽与结构（v2.0 厚板盲孔 + 侧磁 Maglev）

**需要 3D 打印，必须光固化高透树脂（FDM 透明 = 毛玻璃，否掉）；不买打印机，代打。厚板为亚克力定制。**

- **结构（10-02 拍板"简单的一块更厚的亚克力"）**：314.2×201.4×9mm 透明亚克力单块，67 个盲孔（17.6² 方孔 R2、深 6.5 不打穿），键帽块（1u 17×17×7.5，宽键加宽）落入孔中滑动，顶露板面 1.0~1.5mm。图纸 `../02-结构图纸/thickplate-v3.scad`（part=plate/block/test_plate）+ `chassis-v3.1.scad`。
- **侧磁（v5.3 全竖立+贴缝）**：每键 2×N52 4×2 圆盘**竖立**嵌左右侧壁——块外侧面水平打腔（Ø4.1，轴心高 2.05）横插磁铁**完全嵌入帽内**，**同排全部同向**（帽间无互斥；401 胶固定）；外壁 **0.5mm** → **极面间隙 ≈3.0mm**（=2.05 帽间隙+2×外壁；旋钮 wall_t：0.25→2.55mm、0→2.05mm 磁铁齐平——**"2mm 以上即可，无需 5mm"**）；磁心 1u ±7.025、宽键 ±(wu×9.525−2.0−wall_t)。
- **几何红线**：孔间壁只有 1.45mm，Ø4 竖立磁铁**放不进键间的板上**——板侧对斥只能平贴孔底/PCB 面；竖立对竖立的对斥只发生在键帽之间。
- **悬浮与回弹（v5.4 口径）**：同排磁铁全部同向、帽间无互斥；**托浮/回弹 = 键帽磁铁 与 板上竖立磁铁（孔底，同向）的竖直对斥**——板上磁铁同样竖着放，与帽内磁铁逐对竖直对置，压压缩距、松手回弹（竖直弹簧）。帽间缝即标准 2.05，无需加宽。行程 3mm，按到底块底距屏 1.0mm。层高配比 P0′ 实排校验。
- **霍尔摆位（v5.2 变更）**：竖立磁铁**正下方 B_z≈0**——P0′ 用 TO-92 直插现场扫偏位最大点（预计在磁极面侧下方 2~4mm），点位定稿后重出 CSV v5.1，再画 P2 板。
- **兜底阶梯（10-02 拍板）**：单帽试产 → **双磁方案可行就批量**；不行 → **三磁兜底**：竖立×2（保留侧向居中）+ 底心 1 颗（4×2 或 6×3，N 朝下）+ 孔底/PCB 平贴对斥——底心磁铁恢复"霍尔正对+垂直对斥"的 v1.6 成熟路径，信号/悬浮全部有实测背书。
- **防刮**：键帽块底四角 0.3mm Bumpon（按到底距屏 1.0mm 的净距来源）。
- **手感调节**：偏轻 → 磁铁换 6×3 或双 4×2 叠（腔加深 2.1→4.2）；偏重 → 减胶面/微扩孔距。
- **极性实操**：侧壁磁铁全部"同一面朝下"批量压入；装好后任取两邻帽感受互斥即为对（相吸则翻整批，不用逐颗验）。

## 6. 固件骨架（P2 等板期间写完）

VSCode + PlatformIO + Arduino-ESP32：

```cpp
#include <USB.h>
#include <USBHIDKeyboard>
USBHIDKeyboard Keyboard;

const int ADDR[3] = {5, 6, 7};   // 4051 A/B/C
const int ADC_PIN = 4;
uint16_t baseline[64];
uint8_t  keyCh[67]  = { /* 通道映射, 含 M1~M6 */ };
uint8_t  keyCode[61]= { /* HID 键码 */ };

int readCh(uint8_t ch) {
  for (int i = 0; i < 3; i++) digitalWrite(ADDR[i], (ch >> i) & 1);
  delayMicroseconds(20);
  analogRead(ADC_PIN);                       // 弃样
  return analogReadMilliVolts(ADC_PIN);
}

void loop() {
  static uint32_t t = 0;
  if (millis() - t < 8) return;              // ~120Hz 全键扫描（打字级）
  t = millis();
  for (int k = 0; k < 61; k++) {
    int travel = readCh(keyCh[k]) - baseline[keyCh[k]];
    bool pressed = travel > pressThreshold;  // 如 60mV，可调
    // TODO: 迟滞 + RT 快速触发 + 上报/释放
  }
}
```

- 开机静置 3 秒采基线存 NVS；空闲键缓漂慢速跟随（温漂第一道防线）；
- RT 算法抄 [Rapid-trigger-minipad](https://github.com/RQNG/Rapid-trigger-minipad)；
- USB CDC 串口把键程发渲染端做联动。

## 9. 风险表
