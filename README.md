1. **10-13 收货** → 上电自检（VBUS↔GND → 3V3 轨 → LED → USB 枚举）→ 烧固件（octal PSRAM）
2. **磁轴验证 P0′**：厚板下单（V6r 图纸就绪）→ 磁铁（已备）→ 键帽块 P3 待设计 → 手感/回弹/隔屏 Δ 实测

4. **v2 候选清单**：4067 替代 4051（9→5 颗）、chassis 重生成、N16R8V 模组（内置温度传感器）
