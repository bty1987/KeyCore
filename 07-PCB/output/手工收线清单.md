## 建议布线顺序

1. **主控区短线**（上表 1~20 附近：USB/CC/VBUS/UART/1-Wire/LED/3V3 桥）——都在板底部 y<30 区域
2. **EN×9 / Z_COM×9 / MUX_A/B/C 星形 / VDD×9**——沿底边 y>138 汇流带走到各 4051
3. **霍尔 OUT**（大头）——按 4051 分组收：每组 8 键从 4051 X 脚出发往回铺；技巧=先从霍尔过孔**垂直下穿**到本行与下一行之间的空隙（y=行母线附近），再**横向**走到组内 4051 的 x 位置，最后**竖直向下**进 X 脚——同组从左到右依次进线，通道互不交叉
4. 收一条在表里划一条；全部划完后跑 DRC（净距 0.2 / 线宽≥0.25 / 过孔 0.6-0.3）清零
