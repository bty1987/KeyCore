# KeyCore 画线→打板全程总结（过程 · 经验 · 冲突 · 殊途同归）
**2026-10-07 ~ 10-08 · 工程.KeyCore-v43b-3c · 布线 Gerber 已出 · 订单已下（Y4，10-13 发货）**

---

## 〇、一页结论

- **最终方案**：净板（用户手清）→ FreeRouting 全局布线（DSN 剔除 GND/3V3 巨网）→ SES 单源导入 → 重铺 L15 GND/L16 3V3 平面 → **DRC 仅剩 1 项**（USB 差分对等长差 0.8mm，FS USB 电气无影响，用户确认保留）
- **用时对比**：自研 A* 迷宫手搓数小时仍卡死在 MUX 焊盘场 → FreeRouting **1 分 22 秒**布完全板 + 10 分 14 秒优化（改进 51.95%）
- **真正的胜负手**不是"谁更聪明"，而是：**平面/缝合等基础设施先铺好 + 电源网不进自动布线器 + 净板单源导入**。三条缺一，AutoRouter 就卡死或产出混合污染。

## 二、操作流程（可复用的 SOP，按序执行）

### A. 布线前置（未动一根线前）
1. **规则三件套**：`pcb config via --name viaSize` 四值同设（min/max 单设会被配对校验拒）；间距矩阵写回（本板最终用嘉立创真实工艺 **5mil=0.127mm**，6mil 会把可制造贴脸当违规）；差分对声明 `pcb diff-pair create`（USB0 = USB_DP/DN）。
2. **关键网先行**：`pcb route-critical` ——4 层板自动出方案：GND→L15 平面、3V3→L16 平面、VBUS 走线；**顺手在每颗 GND/3V3 焊盘打缝合孔（188 个，多 in-pad）**。
3. **效果立竿见影**：DRC 连接错误 448→0（平面+缝合经 ratline 注册）。**电源网永远不交给走线，交给平面。**

### B. 全局布线（本板的胜负手）
4. `pcb export-dsn` ——已有铜皮以 `(type protect)` 进入 DSN，外部布线器不会动它们。
5. **DSN 文本手术：整块删除 `(net GND ...)`、`(net 3V3 ...)` 及 `(class GND/3V3)` 块**——GND 巨网（212 引脚）是 FreeRouting 1.9.0 卡死的唯一根因（本板实测：不剔除初始化 25min 后死锁；剔除后 **1m22s 完成**）。
6. `java -jar freerouting-1.9.0.jar -de clean.dsn -do routed.ses -mp 99`（Java 17；v2.x 需更高 Java 不用）。
7. `pcb import-autoroute routed.ses` —— **必须是净板**（见 §四.1 混层教训）。

### C. 导入后收尾
8. `pcb save` → `doc reload` → `pcb pour-rebuild` → `pcb drc`（顺序固定；铺铜永远在最后重灌）。
9. 重铺被清掉的平面（本流程 L15/L16 坐标 `[[2.05,-7557],[11808.98,-7557],[11808.98,-2.05],[2.05,-2.05]]`）→ 再 rebuild。
10. 终验双口径：**间距/短路看 DRC（几何判定，可信）；连接类看几何终审**（连接审计随 reload/ratline 波动，0↔54↔230 均出现过，不能作为验收依据）。
11. Gerber：`debug exec` → **`eda.pcb_ManufactureData.getGerberFile()`**（⚠ 必须带 `eda.` 前缀，裸类名报 not defined）→ arrayBuffer→btoa 分块→base64 解码→zip。

### D. 下单防呆（每一行都对应一次真实踩坑）
- Gerber 传**最新** zip（目录里新旧 zip 并存，旧 172mm 板的 zip 名字很像）
- BOM 逐行：数量 ×套数、替换型号封装逐项核（74HC4051D=SOIC-16 ✓；PW=TSSOP ✗ N=DIP ✗）、禁品 C 号扫描、安装孔行删除、直插件选"不贴装"
- 生产稿确认：核对成品尺寸（300×192；生产板 202.1 = 192+两侧 5mm 工艺边，出货单片边已去）

## 三、殊途同归：三条布线路线的完整交锋记录

| 路线 | 战果 | 败因/限制 |
|---|---|---|
| **A. typed 逐段+驱动器 A\*（自研迷宫）** | 总线 MUX_A/B/C、Z_COM、VBUS、ONE_WIRE、UART、LED、EN_1/4/5/6、16 霍尔全部连通 | MUX 焊盘场饱和后失败率飙升：in-pad 孔晕圈（INF 28mil）互封邻脚、共享走廊被先布网吃光、贪心逐网无全局规划。**没有输在算法，输在没有全局通道规划** |
| **B. FreeRouting 全量（不剔电源网）** | 未走通 | GND 巨网 212 脚 → 初始化 25min 后死锁（上一会话已踩） |
| **C. FreeRouting 全量（剔 GND/3V3）** ✅ | **12 分 35 秒完成全板 + 优化 51.95%** | 需要平面承担电源（本板恰好 4 层有平面） |
| D. route-short / route solve | 短线 111 段 ✓；中长线"迷宫层"推诿 | 单层零过孔求解器，跨层场景弱 |
| E. route-critical | 平面+缝合+VBUS 一次成型 | 缝合孔不看 TH 焊盘（J1 壳孔旁冗余孔→间距违规，删掉即消） |

**殊途同归的实质**：A 路线的价值不在"布完了多少"，而在逼出了全部工程事实——行距 19.05、行心坐标、EN_2 走廊占用、烟囱死区成因、J1 焊盘场几何。这些事实让 C 路线的前置（平面、缝合、剔网）做得一次到位。**A 是侦察兵，C 是主力军。**

## 四、冲突点 / 异常点全集（每条都是真实踩坑）

### 混层与导入类
1. **SES 导入到"混层"板 = 灾难**：typed 铜 + SES 铜叠加 → 同位重复过孔 226 个、0 距离交叉 428 处、DRC 2240。**唯一正解：清到净板（保平面缝合孔）单源导入** → 2240→113→1。
2. **getDsnFile 不会丢 typed 铜**（958 段全数进入 DSN 为 protect）——此前"typed 铜导不出"的担心被证伪。

### 连接审计类（验收纪律）
3. **连接审计随 ratline 状态波动**：同一块板先后报 0 / 54 / 230 项 No Connection。裸网不报、部分布线才报、reload 后才重算——**连接类数字永远不能当验收依据**，用 `pcb net-path` 几何证明或单坐标系连通审计。
4. 间距/短路类是纯几何判定，**实时可信**，与连接图无关。

### 几何类
5. **in-pad 缝合孔晕圈互封**：焊盘间距 50mil、孔晕圈 28mil → 相邻两孔即封死中间走廊。这就是 MUX 焊盘场对 A* 不可穿越的物理根源。
6. **A* 刻格副作用**：为起终点"开格"若覆盖异网铜 → 路径从异网铜上踩过 = 真短路。正解是硬/软双栅格（异网硬不可开，同网/膨胀软可开），当时未及实现。
7. **栅格 double+1**：block_rect 的 range 上界多 +1，四边各多堵一圈——走廊恰好 8~10 格宽时被封死。
8. **A* 启发函数曾拿栅格坐标减毫米坐标**（差 ~12 倍）→ 贪心冲进凹形死区烧光预算。
9. **TH 焊盘自连平面**：J1 壳孔（金属化）不需要缝合孔——route-critical 在旁边打的缝合孔是纯冗余 → Hole-to-Hole 违规，删除即消。
10. **"工艺边"**：下单页"板宽 20.21cm" ≠ 板子变宽，是 SMT 传送带夹边 2×5mm，成品仍 300×192（生产稿预览里双框，外框是拼板）。

### 工程管理类
11. **EDA 重连即换窗口 ID**（一晚三变：25d0086c→20d022d3→0878862b）——所有脚本硬编码 W 必须随 health 更新；STALE_WINDOW 报错先查 ID。
12. **驱动器必须每次 fresh dump**：陈旧基线会让整批路由在旧坐标上重画（同一跳重复 120 段 ×N 轮）。
13. **rip-up 输出 `deleted:{}` 为空 = 没删**（EN_2 首rip无效），删除后必须 fresh 核验。
14. **手工布线绕过网格检查 = 必踩坑**：CC2 的 L1 直线"手工验距"漏了 VBUS/CC1/DN 的南下短桩，9 处 0 距离——**任何铜皮落板前都要过一遍含全障碍的栅格**。
15. **CSV/文档过时链**：pcb-hall-positions.csv v5.2 的 y/x 列已过时（EDA 再移 11.337mm）、scad thickplate-v3 整体作废、EDA BOM 绑定字段在 dump/list API 里不暴露（`= {Manufacturer Part}` 模板串才是绑定标志）——**权威坐标只有 EDA live，权威 BOM 只有下单配单结果**。

### BOM/采购类
16. **74HC4051"库存不足"乌龙**：C2943297 的原厂型号本来就是 **74HC4051D**（D=SOIC-16），配单直接以现货锁定，从未需要替换。HCT（5V only）/PW（TSSOP）/N（DIP）/4052/4053/4067 全排除。
17. **J2/J3 直插件"仅采购不贴装"**：BOM 尾部残留两行是合法状态（贴装数=空），用户最终选择删除自购。
18. **禁品清单制度有效**：C2286（0603 装不上）/C39794/C52092029（尺寸不符）/C9900001716（不可下单前缀）/C347222（被替代）——配单扫描零出现，制度成功。
