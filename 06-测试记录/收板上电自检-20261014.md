## 一、断电检查(不插 USB)

> **GND 参考点 = USB-C 的银白色金属外壳**(顶边正中)。⚠ 安装孔 H1~H6 是 NPTH 非金属化孔,孔内无铜、不导电,**不能**当 GND。
> 验证参考点搭好了没有:红笔碰 U2 的 GND 外脚(两外脚中蜂鸣 ≈0 的那只),应读 ≈0.000。

| # | 项目 | 方法 | 合格判据 | 实测 | 结果 |
|---|---|---|---|---|---|
| 1 | 目检 | 正反面放大看 | 无连锡/立碑/板边损伤;5 片抽查 2 片 | | ☐ |
| 2 | VBUS↔GND | USB-C 口 VBUS 对 GND,万用表二极管档 | 不短路(有 0.4~0.6V 压降属 AMS1117/ESD 正常) | | ☐ |
| 3 | 3V3↔GND | U2 输出对 GND,二极管档 | 不短路 | | ☐ |

## 三、烧录自检固件

```
cd 03-固件
pio run -t upload -e bringup && pio run -t monitor -e bringup
```

- 进不去下载模式:按住 BOOT(SW1) → 插 USB → 松开 → 烧录
- 引脚已按 U1 typed 网络表核实:ADC=IO4(网络 Z_F)、MUX_A/B/C=IO5/6/7、EN_1..9=IO8~16 低有效
- 串口 115200,判定:

| # | 项目 | 串口输出 | 合格判据 | 实测 | 结果 |
|---|---|---|---|---|---|
| 7 | 芯片 | `芯片: ESP32-S3 rev? @ 240 MHz` | 型号正确 | | ☐ |
| 8 | Flash | `Flash: 4096 KB` | = 4MB | | ☐ |
| 9 | PSRAM | `PSRAM: OK, 8388608 bytes` + 读写 OK | = 8MB OPI;**FAIL 先查 qio_opi 配置** | | ☐ |
| 10 | LED1 | 板上红光 LED | 每 0.5s 闪(USB 口旁硬件带) | | ☐ |
| 11 | 采样链静态 | `sweep#n ok=?/72` | **ok ≥ 67**,ok 格 ≈1650mV;全 0/全 4095 = ADC 脚有误 | ok= | ☐ |
| 12 | 采样链动态 | 磁铁逐键位靠近 | 对应键位弹 `ALERT`,Δ 单向、随距离加大 | | ☐ |

- 72 通道 = 67 霍尔 + 5 空槽(空槽数值不定属正常;哪 5 格空可反查扫描表)
- 磁铁扫完一圈后:串口发任意字符重取基线
- 串口原始输出建议存 `P0'` 同款 log:`pio device monitor > 收板扫描.log`
