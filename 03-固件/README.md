# P0 单键验证 · 测试流程（30 分钟出结论）

## 接线

```
49E 霍尔（平面对自己，三脚朝下）:
  [VCC] → ESP32-S3 3V3
  [GND] → GND
  [OUT] → GPIO4
```

49E 三脚无明确丝印时：TO-92 封装字面朝自己、脚朝下，从左到右 = VCC / GND / OUT（以 datasheet 为准，接反一般不烧但读数不对）。

## 编译上传

```bash
cd 透明键盘-P0验证
pio run -t upload && pio device monitor      # PlatformIO
# 或 Arduino IDE 2.x: 装 esp32 板包 → 打开 src/main.cpp → 选 ESP32S3 Dev Module → 上传 → 串口绘图器
```

## 测试五步（对应验收项）

1. **基线**：上电静置，串口看 raw ≈ 1600~1700mV（≈VCC/2）。基线飘说明旁边有磁铁或电源噪声。
2. **穿屏信号**：磁铁 6×3（N 极朝玻璃/亚克力）放在**模拟堆叠**上面：
   - `亚克力 5mm（当盖板）+ 空气隙 ≈4mm + 亚克力 4mm（当屏体）`，霍尔贴最底下；
   - 从 15mm 高度缓慢压到 6mm，看串口绘图曲线。
3. **验收**：曲线**单调、无毛刺**；记录 10mm 和 6mm 两点的 delta_mv → **Δ≥80mV 过关**。
   - 出现平台期（电压不再变化）= 霍尔进入饱和区，正常，记录 6~10mm 段即可；
   - Δ<80mV → 应急方案：**两颗 6×3 叠加**（厚度加倍≈8×3 场强）重测；叠用过关 → 感应磁铁改双 6×3 方案（键帽磁铁腔加深即可，图纸改 sense_h 一个参数）。
4. **极性**：磁铁翻面（S 极朝下）曲线应反向下行——确认正式装配时 N 朝下。
5. **悬浮手感**：两颗 4×2 同极（N 对 N）相对，5~8mm 间距按压，感受 30~60g 回弹，是否可接受（不可接受 → 文档 §10 调参选项）。

## 老屏速测（若用拆机 Acer 屏当测试板）

CCFL 屏总厚 5.5~6mm = 更苛刻条件：直接霍尔贴白色背板、磁铁压玻璃面测试。**老屏过关 = 新屏（2.5mm）必过**。注意别碰下边缘的高压逆变条、老屏不通电。
