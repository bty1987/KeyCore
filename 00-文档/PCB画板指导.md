## 二、霍尔摆放（最关键——决定按键能不能用）

### 位置规则

**每颗霍尔 = 键心坐标 + (−6, 0)**，即从键位中心**向左偏移 6mm**，Y 不动。

**所有 67 键方向统一**（不交替、不镜像、不旋转）——从上往下看，霍尔永远在键心的左侧。

### 精确坐标表（CSV 直接导入）

文件：`02-结构图纸/pcb-hall-positions.csv`

- 列 `hall_x` / `hall_y` = 霍尔**放置中心点**（EDA 顶视图，元件面朝上，原点=板左下角）
- 坐标系：+x 向右，+y 向后（Esc/宏行方向）
- 精度：小数点后三位（μm 级），EDA 中直接输入

### 封装

- SOT-23（立创贴片库搜 `HAL49E` 或 `49E`，选 SOT-23 封装、基础库 TAB 有货的）
- **丝印标注键名**（如 K01=Esc, K62=M1），方便验板和售后

### 摆放操作

1. 立创EDA 中打开 CSV → 或用脚本批量放置
2. 每颗霍尔确保**引脚 1（标记得号的一端）朝同一方向**（建议朝上/+y）
3. 摆完后 DRC → 导出 Gerber + 坐标文件

## 三、多路复用器（74HC4051）

| 参数 | 值 |
|---|---|
| 数量 | **9 片** 74HC4051D（SOIC-16）|
| 位置 | PCB **前段 y=0~23mm 条带**（避开键区，键区从 y=23.1 开始） |
| 接线 | 67 霍尔 OUT → 分到 9 片 4051 的 X0~X7（72 通道，空 5 路） |
| 地址线 | 9 片 A/B/C **并联** → ESP32 三个 GPIO（建议 GPIO 5/6/7） |
| 使能 | 9 片 E 脚全部接地 |
| 输出 | 9 片 Z 输出**并联** → ESP32 ADC（建议 GPIO 4） |
| RC 滤波 | Z 输出与 ADC 之间：100Ω 串联 + 100nF 对地 |

## 四、ESP32-S3-WROOM-1 最小系统

| 项目 | 值 |
|---|---|
| 模组 | ESP32-S3-WROOM-1-N4（立创贴片库） |
| 位置 | PCB 前段左侧（USB-C 旁边） |
| USB-C | 16P 母座，CC 5.1kΩ ×2，D+/D- → GPIO19/GPIO20 |
| LDO | ME6211C33（SOT-223），USB 5V → 3.3V |
| 按键 | EN（复位）+ BOOT（下载）各 1 颗轻触开关 |
| 天线 | 模组天线区**超出板框或板边开槽**（确保无铜遮挡） |
| Strapping | GPIO0/45/46 按模组手册典型电路处理 |

### GPIO 分配表

| GPIO | 用途 |
|---|---|
| 4 | ADC 输入（4051 Z 汇聚） |
| 5 | 4051 地址 A |
| 6 | 4051 地址 B |
| 7 | 4051 地址 C |
| 19 | USB D- |
| 20 | USB D+ |
| 0 | BOOT 按键 |
| 3 | EN 按键（或直连 EN） |
| 8 | DS18B20 数据（温补传感器，可选） |

## 五、Layout 规则

1. **模拟区**（67 霍尔 + 4051 走线）铺完整地平面，模拟信号线尽量短且等长
2. **霍尔到 4051** 的走线：每根独立，不共享，避免串扰
3. **ESP32 天线区**：板边向外延伸 ≥5mm 无铜
4. **丝印**：每颗霍尔旁标键名（K01~K67），4051 标 U1~U9
5. **USB-C** 在 PCB 左边缘（前面板方向）
6. **定位孔**：四角 M3（Ø3.2），距板边 6mm
7. **Keep-out**：键区 y≥23.1 范围内，**不放任何高于 1.5mm 的元件**（霍尔 SOT-23 高度 ~1.4mm 刚好通过）
