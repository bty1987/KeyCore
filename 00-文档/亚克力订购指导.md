## 二、孔位坐标（67 孔 + 134 磁铁腔）

**坐标原点 = 板左下角**（非 PCB 坐标，差一个偏移量）。

### 换算公式

```
板孔中心 x = PCB hall_x + 6 + 7.1 = CSV 键心x + 7.1
板孔中心 y = PCB hall_y + 23.1 = CSV 键心y + 23.1
```

### 坐标表

从 CSV `pcb-hall-positions.csv` 中读取 `hall_x`/`hall_y`，套入上式。

或直接从以下文件获取已换算的坐标：
- `02-结构图纸/frame-plate-coords.scad`（OpenSCAD 数组，每行一个孔）
- `02-结构图纸/export-thickplate-v30.stl`（3D 模型，可用 CAD 软件测量）

### 磁铁腔位置（每孔 2 个）

```
磁腔 1 中心 = (板孔中心 x − 6, 板孔中心 y)
磁腔 2 中心 = (板孔中心 x + 6, 板孔中心 y)
```

**所有 67 孔的磁腔方向统一**：左右各一个，不交替不镜像。

## 三、关键公差（厂家必须确认）

| 项目 | 公差 | 为什么重要 |
|---|---|---|
| 孔位中心距 | **±0.15 mm** | 偏了按键歪、磁路错位 |
| 孔边长 | 16.9 **+0.1/−0** | 太大键帽晃、太小键帽卡死 |
| 孔深 | 6.5 **+0.2/−0** | 太深板底穿、太浅键帽凸太多 |
| 磁腔直径 | Ø4.2 **+0.1/−0** | 太大磁铁松脱、太小压不进 |
| 磁腔深度 | 2.2 **+0.2/−0** | 太深穿入孔底（磁铁会突出碰键帽） |
| 磁腔底到孔底面 | **≥1.0 mm**（设计 1.3） | 太薄受力断裂 |

**⚠️ 最容易做错的地方：**
1. **盲孔不打穿**——底面必须保留 3.5mm 整体厚度
2. **磁铁腔从底面铣**，不是从顶面——方向搞反整板报废
3. **浇注板不要挤出板**——挤出板内应力大，CNC 后翘曲

## 五、验收清单（到货后逐项检查）

- [ ] 板厚 10.0mm（卡尺量，±0.2）
- [ ] 孔深 6.5mm（深度尺或磁铁试插）
- [ ] 孔底未打穿（手指摸底面应平整无凹陷）
- [ ] 磁腔 Ø4.2×2.2（4×2 磁铁轻压入，不松不紧）
- [ ] 磁腔底面距孔底 ≥1.0mm（从底面孔位透光看，不应看到磁腔底部）
- [ ] 67 孔位置抽样（用键帽块试插 3~5 个孔，应顺畅滑动无卡涩）
- [ ] 测试样块同批验收
