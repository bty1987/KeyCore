# KeyCore 文档索引

| 文档 | 用途 | 读者 |
|---|---|---|
| `v3.0-总架构.md` | 三层结构总说明（尺寸链/磁路/流程/废弃方案） | 所有人 |
| `PCB画板指导.md` | 霍尔精确坐标/4051 接线/GPIO 分配/BOM/下单参数 | 画板对话 |
| `亚克力订购指导.md` | 板规格/孔位坐标/公差/验收清单/参考价 | 亚克力厂家 |

## 使用方式

1. **画板**：把 `PCB画板指导.md` + `layout.json` 转给画板对话
2. **亚克力**：把 `亚克力订购指导.md` + 订购图 + STL 发给厂家询价
3. **装配/测试**：按 `v3.0-总架构.md` 第五节测试流程走
