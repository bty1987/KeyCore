## 二、三层结构

```
层① 亚克力板（10mm）—— 键帽载体 + 磁铁腔 + 顶面外观
    67 盲孔 Ø16.9 深 6.5（不打穿，底留 3.5）
    134 磁铁腔 Ø4.2 深 2.2（从背面铣，正对每孔 (±6,0)）
    磁铁腔嵌 4×2 N 朝上（与块底磁铁对斥）

层② IPS 屏（2.5mm）—— 键位字符显示
    13.3 寸 1080P，有效区 293.7 × 165.2 mm

层③ 霍尔 PCB（1.6mm）—— 按键检测
    67 颗 SOT-23 霍尔（每键 1 颗，位于键心偏 (−6,0)）
    9 片 74HC4051 多路复用 → ESP32-S3 → USB HID
    ★ PCB 上无任何磁铁（磁铁全在亚克力板里）
```

### 磁路原理（一句话）

键帽块底面两颗 4×2（N 朝下）→ 穿过亚克力孔底 1.3mm + 空气 → 与板腔内两颗 4×2（N 朝上）**对斥** → 斥力把键帽块顶在孔内上止位（悬浮静止），按压压缩斥力，松手弹回。霍尔在左磁铁正下方感知移动磁场变化。

## 三、坐标体系（唯一数据源）

```
layout.json ← 唯一权威
├── PCB 霍尔位 = 每键 (键心x − 6, 键心y)
├── 亚克力磁腔 = 每键 (键心 ±6, 键心y)  
└── 显示层字符 = 每键键心（换算至屏物理尺寸）

坐标转换公式（固定）：
  亚克力孔心 = (键心x + 7.1, 键心y + 23.1)    （板坐标）
  磁腔中心   = (孔心 ±6, 孔心y)               （同上）
  显示层 px  = ((键心x − 3.15) × 6.537, (183.3 − 键心y) × 6.537)
```

## 五、测试流程（不可跳过）

```
亚克力到货
  ↓
单键测试（用样块）
  · 磁铁嵌入板腔（N 朝上）
  · 键帽块（手切亚克力方块即可）底面贴两颗磁铁（N 朝下）
  · 霍尔贴样块底面左磁腔正下方
  · 磁铁靠近/远离 → 串口看 Δ
  ↓
Δ ≥ 30mV？
  ├── 是 → 批量键帽（两磁版 keycap-block-final.stl）→ 装配 → 全键联调
  └── 否 → 退三磁铁方案（v1.9：感应磁铁独立、霍尔键心正下）→ 重出键帽 STL → 再测
```

## 六、已废弃方案（留档不删，防止回退）

| 版本 | 方案 | 废弃原因 |
|---|---|---|
| v1.6 | 盖板开孔穿脖子 + 三磁铁底面中心 | 孔洞体验差、磁铁挡字符光路 |
| v1.8 | 两颗对角悬浮 + 霍尔 rep1 正下方 | 霍尔与 PCB 磁铁撞位（同一物理点） |
| v2.0 | 两颗对角 + 霍尔内移 4mm 交替 | 实测 Δ48mV 可用但架构不如 v3.0（PCB 仍需贴 134 磁铁） |
| 三段式键帽 v2 | 头/腰法兰/裙身 | 键帽异形复杂、观感不如整块厚板 |
